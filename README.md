# 【美少女】ド美少女バ美肉ちゃんにドスパチャをした結果...！？【可愛い】
本ゲームはサークル内の4日間ゲーム制作イベントにて、自身を含めた10名のチームで開発しました。

## 概要
配信しているVtuberがプレイしている2D横スクロールアクションゲーム内のキャラクターを操作してゴールを目指します。
スーパーチャットを送ることで画面上にコメントが流れ、コメントに応じた能力をキャラクターに付与します。

開発期間: 4日間

プラットフォーム: PC (Windows)

## 開発環境
言語: C#
ゲームエンジン: Unity 2022.3.21f1

私は、タイトル/リザルト画面のUI、シーン間におけるスコアの受け渡し、BGMの再生機能、表示コメントのアニメーションの一部を担当しました。
