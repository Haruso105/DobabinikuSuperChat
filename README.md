# 【美少女】ド美少女バ美肉ちゃんにドスパチャをした結果...！？【可愛い】

## 開発体制
サークル内の4日間ゲーム制作イベントにて、10名のチームで開発しました。
※ポートフォリオへの掲載および公開の合意を得ています。

- **開発期間:** 4日間
- **プラットフォーム:** PC (Windows)
- **使用技術:** Unity 2022.3.21f1 / C#

## ゲーム概要
配信中のVtuberがプレイしているゲームという設定の、メタ要素を含む2Dアクションゲームです。
視聴者（プレイヤー）が「スーパーチャット」を送ることで、画面上にコメントが流れ、その内容に応じてキャラクターに様々な能力が付与されるのが特徴です。

## 工夫・苦労した点

### 1. DOTweenを活用した直感的なUI演出
ユーザー体験（UX）を向上させるため、タイトル画面のボタンにアニメーションを実装しました。
DOTweenを使用することで、カーソルを合わせた際のスムーズな拡大演出を軽量かつ短期間で実装し、ゲームの第一印象となるメニュー画面のクオリティを高めました。

### 2. 大規模チームにおける開発フローの最適化
グループでの4日間開発において、最大の懸念はGitHub上でのコンフリクトでした。
これを未然に防ぐため、メンバーごとのフォルダ分けを実施し、スクリプトや素材を個別に管理する体制を整えました。これにより、コンフリクトを起こすことなく円滑にグループ開発を行うことができました。
